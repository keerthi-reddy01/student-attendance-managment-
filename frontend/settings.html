About AttendX

Student Attendance Management System using DevOps tools.

v1.0.0

Application

Node.js 24 · Express 5 · SQLite (built-in) · HTML/CSS/JavaScript. Seven periods per day, date-wise storage, monthly analytics and CSV reports.

DevOps

Git version control, Jenkins declarative pipeline, Docker multi-stage image, Kubernetes Deployment + Service + PVC, and Selenium WebDriver tests.

Data

All student and attendance data is persisted in a SQLite database with WAL journaling. The location is controlled by the DATA_DIR environment variable.
